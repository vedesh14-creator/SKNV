# SMOKE-FREE 30 Android project

This is an Android Studio project source, not a precompiled APK.

## Build an APK
1. Install Android Studio on a computer.
2. Open this folder (`SmokeFree30`) in Android Studio.
3. Let Gradle sync and install any requested Android SDK (compile SDK 35).
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will show the APK location, usually `app/build/outputs/apk/debug/app-debug.apk`.

The debug APK can be installed on your Android phone after transferring it. Android may ask you to allow installation from that source.

## Notes
- This first version stores a quit date and displays a streak, milestones, recovery timeline, craving tips, and estimated money saved.
- The app is educational and does not replace medical advice.
- To set the correct streak, update the quit date in a future version; this starter version uses the current date on first launch.
